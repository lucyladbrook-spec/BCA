# Bengeo Nature Explorers

A pupil-facing website supporting Bengeo Climate Action at Bengeo Primary School.
*Small hands. Real change.*

## What's here

| File | What it is |
| --- | --- |
| `index.html` | The whole website in one file. Open it in any browser, no setup needed. |
| `mission-sheets.pdf` | Printable A4 activity sheets, one per mission. |

## Editing the site

All the content lives in the `DATA` block near the bottom of `index.html`:
missions, curriculum links, map zones, photos and the weekly Energy Garden symbols.
Change the text there and save. The design rebuilds itself from it.

## Ground rules

- No pupil names, photos of identifiable children without consent, or school data in this repository.
- Energy Garden symbols are set by the School Business Manager. Figures are never published.
- Anything marked "Idea" is a proposal until agreed.
